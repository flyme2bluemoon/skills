# AGENTS.md

Many of Matt Pocock's skills rely on each other. Therefore, when the user asks you to create a skill based on a Matt Pocock skill, make sure you check that its dependecies are already created and present in `skills/`. If they have already been created, make sure you read them to understand how they may differ from Matt Pocock's version. If they have not been created yet, consider whether you should ask the user to create those skills first before continuing.
